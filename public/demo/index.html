Das ist JPad

JPad ist eine Werkstatt für Java, gebaut für das iPad. Du schreibst Code, ohne viel tippen zu müssen, und siehst sofort, was dein Programm tut. Tippe auf die Nummern im Bild:

Tippe auf eine Nummer.

Das Wichtigste zuerst: die Glühbirne

Oben in der Kopfzeile leuchtet eine gelbe Glühbirne. Sie erinnert dich an den wichtigsten Trick in JPad:

Weißt du nicht, was ein Knopf tut? Lege einfach eine halbe Sekunde lang den Finger darauf.

Dann erscheint eine Hilfe, und der Knopf wird nicht ausgelöst. Das klappt bei jedem Knopf und jedem Baustein. Bei den Bausteinen bekommst du sogar eine große Hilfe mit Beispielen.

Probier es aus

a) Tippe in JPad auf die Glühbirne. Was steht in dem Hinweis?

b) Lege den Finger eine halbe Sekunde auf den Baustein Klasse links. Was erklärt dir JPad?

Lösung anzeigen
Die Glühbirne erklärt das lange Drücken. Beim Baustein Klasse erscheint eine große Hilfe: Eine Klasse ist ein Bauplan für viele gleichartige Objekte. Tippe auf das ✕ oder daneben, um die Hilfe zu schließen.

Baustein „Klasse“

Die Klasse Hund

Eine Klasse ist ein Bauplan. Sie legt fest, welche Eigenschaften (Attribute) und Fähigkeiten (Methoden) alle Objekte dieser Art haben. Jeder Hund hat einen Namen und ein Alter. Das sind die ersten beiden Attribute:

  1. Tippe oben auf Kopieren.
  2. Tippe in JPad links auf den Baustein Klasse.
  3. Gib als Namen Hund ein, mit großem H. Klassennamen beginnen immer mit einem Großbuchstaben.
  4. Tippe auf Klasse als Datei anlegen. Oben erscheint ein neuer Reiter Hund mit dem Klassengerüst. Der Cursor blinkt schon in der leeren Zeile zwischen den geschweiften Klammern.
  5. Halte den Finger in diese leere Zeile und wähle Einsetzen.

So sieht deine Datei Hund danach aus:

Gut zu wissen

JPad rückt den Code beim Einfügen von Bausteinen automatisch ein. Sieht dein Code trotzdem einmal unordentlich aus, tippe oben auf Code formatieren.

Baustein „Attribut“

Ist Bello stubenrein?

Ob ein Hund allein daheim bleiben darf, hängt davon ab, ob er stubenrein ist. Dafür bekommt die Klasse ein drittes Attribut. Diesmal ohne Kopieren, mit dem Baustein:

  1. Tippe links auf den Baustein Attribut.
  2. Wähle als Datentyp Boolean. Ein Hund ist entweder stubenrein (true) oder nicht (false).
  3. Gib als Namen istStubenrein ein und tippe auf Einfügen.

JPad setzt das neue Attribut unter die anderen Attribute, egal wo der Cursor gerade steht:

Kurz nachgedacht

Warum heißt das Attribut istStubenrein und nicht einfach stubenrein?

Lösung anzeigen
Beides wäre erlaubt. Mit „ist…“ liest sich ein Boolean wie eine Ja-Nein-Frage: Ist Bello stubenrein? – true. Das macht den Code leichter lesbar. Namen von Attributen beginnen immer mit einem Kleinbuchstaben, jedes weitere Wort mit einem Großbuchstaben.
5
Neu

Was ist eine Methode?

Attribute beschreiben, was ein Hund hat. Methoden beschreiben, was ein Hund kann. Eine Methode ist ein Stück Code mit einem Namen. Ruft man sie auf, wird ihr Code ausgeführt.

Eine Methode hat einen Kopf und einen Rumpf in geschweiften Klammern. Tippe auf die Teile des Methodenkopfs:

{ … }

Tippe auf ein Teil.

Unsere Methode soll prüfen, ob der Hund stubenrein ist, und das Ergebnis ausgeben. Dafür braucht sie eine Verzweigung mit if und else: Wenn die Bedingung wahr ist, läuft der erste Teil, sonst der zweite.

6
Bausteine „Methode“, „if – else“, „println“

Die Methode bauen

Jetzt baust du die Methode in der Klasse Hund, Baustein für Baustein. Achte darauf, dass der Reiter Hund geöffnet ist.

  1. Tippe auf den Baustein Methode. Es öffnet sich der Dialog „Baue Deine neue Methode“.
  2. Gib als Namen kannAlleinDaheimSein ein. Bei der Frage nach der Rückgabe bleibt void stehen. Parameter brauchst du keine, lass das Feld „So heißt der Parameter“ also leer. Tippe auf Einfügen.
  3. Die leere Methode steht jetzt am Ende der Klasse, der Cursor blinkt in ihrem Rumpf. Tippe auf den Baustein if – else.
  4. Das Wort Bedingung ist markiert. Tippe einfach los und ersetze es durch istStubenrein == true.
  5. Platziere jetzt mit Finger, Maus oder Tastatur den Cursor im Rumpf der if-Anweisung (also innerhalb der geschweiften Klammern).
  6. Tippe auf den Baustein println und schreibe in die Klammern: name + " darf allein daheim bleiben."
  7. Platziere den Cursor genauso im Rumpf von else, also in der leeren Zeile zwischen } else { und }.
  8. Noch einmal println, diesmal mit name + " muss noch üben."

Wenn alles geklappt hat, sieht deine Klasse so aus. Vergleiche genau, oder kopiere die Lösung, falls etwas schiefgegangen ist:

Rot unterstrichen?

JPad prüft deinen Code schon beim Schreiben. Eine rote Wellenlinie zeigt einen Fehler. Was nicht stimmt, siehst du rechts in der Ansicht Probleme. Tippst du dort auf einen Fehler, springt JPad an die richtige Stelle.

7
Baustein „Variable“

Bello wird gebaut

Die Klasse ist nur der Bauplan. Damit es einen echten Hund gibt, musst du ein Objekt erzeugen. Das passiert im Hauptprogramm, dem Reiter ganz links.

  1. Tippe oben auf den Reiter Hauptprogramm.
  2. Tippe auf den Baustein Variable. Wähle unter Eigene Klassen den Datentyp Hund und gib den Namen bello ein.
  3. Unter Verfügbare Konstruktoren ist schon new Hund() ausgewählt. Die Klasse hat keinen eigenen Konstruktor, deshalb gibt es nur diesen Standardkonstruktor. Unten zeigt die Vorschau, was eingefügt wird: Hund bello = new Hund(); Tippe auf Einfügen. Erst jetzt gibt es Bello wirklich.
  4. Kopiere die folgenden Zeilen und setze sie in eine neue Zeile darunter ein. Sie füllen Bellos Attribute und rufen seine Methode auf.

Starte dein Programm mit ▶ oben rechts.

Und wo ist jetzt der Lernpfad?

Beim Start schaltet JPad die rechte Ansicht auf Ausgabe, damit du sofort siehst, was dein Programm schreibt. Der Lernpfad ist nicht weg, er liegt nur dahinter.

  • iPad quer: Tippe rechts oben auf den ersten Reiter mit dem Wegweiser-Symbol .
  • iPad hochkant: Tippe unten in der Leiste auf Lernpfad, und mit Code kommst du zurück zum Editor.

In der Ausgabe sollte stehen:

Ausgabe
Bello darf allein daheim bleiben.
Experimente

a) Ändere im Hauptprogramm true in false und starte noch einmal. Was gibt Bello jetzt aus?

Lösung anzeigen
Bello muss noch üben. Die Bedingung istStubenrein == true ist jetzt falsch, deshalb läuft der else-Teil.

b) Lege einen zweiten Hund wuffi an, der 1 Jahr alt und nicht stubenrein ist, und lass auch ihn antworten.

Lösung anzeigen

Beide Hunde wurden nach demselben Bauplan gebaut, haben aber eigene Werte. Deshalb antworten sie verschieden.

8
Zuschauen

Schritt für Schritt

Mit ▶ läuft dein Programm in einem Rutsch durch. Mit dem Knopf Schritt kannst du ihm dagegen beim Arbeiten zusehen, Zeile für Zeile.

  1. Wechsle rechts zur Ansicht Variablen.
  2. Tippe oben auf Schritt. Das Programm startet und hält sofort vor der ersten Zeile an. Diese Zeile ist gelb markiert: Sie ist als Nächstes dran.
  3. Tippe weiter auf Schritt und beobachte die Ansicht Variablen: Erst taucht bello auf, dann bekommt er nach und nach seinen Namen, sein Alter und istStubenrein.
  4. Bei bello.kannAlleinDaheimSein(); springt JPad mit dem nächsten Schritt in den Reiter Hund, direkt in die Methode. Du siehst, welcher Teil der Verzweigung ausgeführt wird.
Die kleinen Schritt-Knöpfe

Solange das Programm angehalten ist, erscheinen neben Schritt zwei weitere Knöpfe: Methode überspringen führt einen Methodenaufruf in einem einzigen Schritt aus, Methode verlassen läuft bis zum Ende der aktuellen Methode. Mit ■ beendest du das Programm. Und weißt du nicht mehr, welcher Knopf was macht? Finger drauflegen!

Haltepunkt und Diagramm

Bello im Objektdiagramm

Bei langen Programmen dauert es, mit Schritt bis zur spannenden Stelle zu kommen. Dafür gibt es Haltepunkte: Das Programm läuft normal los und hält erst an der markierten Zeile an.

  1. Tippe im Hauptprogramm auf die Zeilennummer der Zeile bello.kannAlleinDaheimSein();. Links neben der Nummer erscheint ein oranger Punkt: Hier ist jetzt ein Haltepunkt. Alternativ setzt du den Cursor in die Zeile und tippst in der Hilfsleiste auf .
  2. Öffne rechts die Ansicht Diagramm und tippe oben auf Objekte.
  3. Starte mit ▶. Das Programm hält vor der markierten Zeile an.
  4. Im Objektdiagramm siehst du jetzt Bello als Karte: oben bello : Hund, darunter alle Attribute mit ihren Werten.
Beobachte

a) Tippe im Diagramm oben auf Klassen. Was ist der Unterschied zur Ansicht Objekte?

Lösung anzeigen
Das Klassendiagramm zeigt den Bauplan: die Klasse Hund mit ihren Attributen, deren Datentypen und der Methode. Das Objektdiagramm zeigt die gebauten Objekte mit ihren aktuellen Werten. Von einer Klasse kann es viele Objekte geben.

b) Hast du in Station 7 auch Wuffi angelegt? Setze den Haltepunkt ans Ende des Programms. Wie viele Karten zeigt das Objektdiagramm?

Lösung anzeigen
Zwei: bello : Hund und wuffi : Hund. Jedes new baut genau ein Objekt.

Einen Haltepunkt entfernst du, indem du noch einmal auf die Zeilennummer tippst.

10
Abschluss

Das Wichtigste in vier Fragen

Noch zwei Helfer für später
  • Umbenennen (der Stift neben Rückgängig): Gefällt dir ein Name nicht mehr, ändert JPad ihn überall im Projekt auf einmal.
  • Projekt sichern (der Pfeil nach unten): Speichert dein Projekt als Datei, zum Beispiel in deinem ByCS-Ordner. Ein Punkt am Pfeil zeigt, dass es noch ungesicherte Änderungen gibt.

Demo-Lernpfad zu JPad. Deine Häkchen werden mit dem Projekt auf diesem Gerät gemerkt. Du kannst das Demo-Projekt jederzeit über das Menü neu laden.
