Das ist JPad

JPad ist eine Werkstatt für Java, gebaut für das iPad. Du schreibst Code, ohne viel tippen zu müssen, und siehst sofort, was dein Programm tut. Tippe auf die Nummern im Bild:

Bausteine „Klasse“ und „Attribut“

Ein Bauplan für viele Hunde

Bello, Cara, Maja … Jeder Hund ist anders, aber alle haben dieselben Eigenschaften: einen Namen, ein Alter und die Angabe, ob sie stubenrein sind. Statt jeden Hund einzeln zu beschreiben, programmierst du einmal einen Bauplan. Nach diesem Bauplan kann JPad danach beliebig viele Hunde bauen.

So einen Bauplan nennt man Klasse. Man zeichnet ihn als Klassenkarte: oben der Name der Klasse, darunter ihre Eigenschaften, die Attribute, jeweils mit Datentyp.

Hund
name: String
alter: Integer
istStubenrein: Boolean

Die Klassenkarte Hund mit drei Attributen. Das untere Fach ist noch leer, dort stehen später die Methoden.

Diese Klassenkarte baust du jetzt in JPad, ganz ohne Tippen: nur mit Bausteinen.

Die Klasse anlegen

  1. Tippe in JPad links auf den Baustein Klasse.
  2. Gib als Namen Hund ein, mit großem H. Klassennamen beginnen immer mit einem Großbuchstaben.
  3. Tippe auf Klasse als Datei anlegen. Oben erscheint ein neuer Reiter Hund mit dem Klassengerüst. Der Cursor blinkt schon zwischen den geschweiften Klammern.

Die drei Attribute einfügen

  1. Tippe auf den Baustein Attribut. Wähle als Datentyp String und gib den Namen name ein. Unten zeigt dir die Vorschau, was eingefügt wird. Tippe auf Einfügen.
  2. Noch einmal Attribut: Datentyp Integer, Name alter.
  3. Und ein drittes Mal: Datentyp Boolean, Name istStubenrein. Ein Hund ist entweder stubenrein (true) oder nicht (false).

JPad setzt jedes neue Attribut unter die anderen, egal wo der Cursor gerade steht. So sieht deine Datei Hund danach aus:

Kurz nachgedacht

a) Vergleiche den Code mit der Klassenkarte. Was steht im Code vorne, was auf der Karte hinten?

Lösung anzeigen
Im Code steht der Datentyp vorne und der Name dahinter: String name;. Auf der Klassenkarte ist es umgekehrt: name: String. Gemeint ist beide Male dasselbe.

b) Warum heißt das Attribut istStubenrein und nicht einfach stubenrein?

Lösung anzeigen
Beides wäre erlaubt. Mit „ist…“ liest sich ein Boolean wie eine Ja-Nein-Frage: Ist Bello stubenrein? – true. Namen von Attributen beginnen immer mit einem Kleinbuchstaben, jedes weitere Wort mit einem Großbuchstaben.
Vertippt?

Mit dem Stift oben in der Kopfzeile (Umbenennen) kannst du einen falschen Namen überall auf einmal korrigieren. Und mit Rückgängig nimmst du den letzten Schritt zurück.

Baustein „Variable“

Bello und Cara werden gebaut

Die Klasse ist nur der Bauplan. Damit es einen echten Hund gibt, musst du ein Objekt erzeugen. Das passiert im Hauptprogramm, dem Reiter ganz links. Dort startet dein Programm.

Hund h1: Bello

  1. Tippe oben auf den Reiter Hauptprogramm.
  2. Tippe auf den Baustein Variable. Wähle unter Eigene Klassen den Datentyp Hund und gib den Namen h1 ein.
  3. Unter Verfügbare Konstruktoren ist schon new Hund() ausgewählt. Die Vorschau zeigt Hund h1 = new Hund(); Tippe auf Einfügen. Erst jetzt gibt es diesen Hund wirklich.

Jetzt bekommt Bello seine Werte. Dafür hilft dir die Hilfsleiste unten am Bildschirm. Sie enthält Zeichen, die auf der iPad-Tastatur schwer zu finden sind, und Knöpfe zum Bearbeiten von Zeilen:

  1. Tippe in der Hilfsleiste auf Zeile einfügen ②. Unter Hund h1 = new Hund(); entsteht eine leere Zeile, der Cursor steht schon darin.
  2. Tippe h1. (mit Punkt). JPad schlägt dir jetzt die Attribute des Hundes vor. Wähle name.
  3. Tippe auf die Taste = ①. JPad schreibt = ; und setzt den Cursor genau vor den Strichpunkt. Gib dort mit der Taste " " den Namen "Bello" ein. Jetzt steht da: h1.name = "Bello";
  4. Wieder Zeile einfügen ②, dann h1.alter, die Taste = und 3. Genauso h1.istStubenrein mit dem Wert true.
Tipp: Enter springt hinter den Strichpunkt

Steht der Cursor direkt vor einer schließenden Klammer oder einem Strichpunkt, springt die Enter-Taste der Tastatur dahinter und beginnt eine neue Zeile. Vor einem schließenden Anführungszeichen springt sie nur hinter das Zeichen. So musst du den Cursor kaum von Hand setzen.

Der Punkt

h1.name bedeutet: das Attribut name des Hundes h1. Texte stehen in Anführungszeichen, Zahlen und true/false nicht.

Hund h2: Cara

Jetzt du

Lege darunter einen zweiten Hund h2 an. Sie heißt Cara, ist schon 16 Jahre alt und nicht mehr stubenrein.

Lösung anzeigen

Beide Hunde wurden nach demselben Bauplan gebaut, haben aber eigene Werte.

Denkaufgabe

Du möchtest auch den Welpen Maja anlegen. Sie ist erst ein halbes Jahr alt. Was müsstest du im Code ändern?

Lösung anzeigen

Ein halbes Jahr ist 0.5, also eine Kommazahl. In ein Integer passen aber nur ganze Zahlen. Das Attribut alter müsste deshalb in der Klasse Hund den Datentyp Double bekommen: Double alter;

Dann ginge h3.alter = 0.5;, mit Punkt statt Komma. Die anderen Hunde dürften weiter 3 und 16 haben, denn ganze Zahlen passen auch in ein Double.

5
Wiederholung

Was ist eine Methode?

Attribute beschreiben, was ein Hund hat. Methoden beschreiben, was ein Hund kann. Eine Methode ist ein Stück Code mit einem Namen. Ruft man sie auf, wird ihr Code ausgeführt.

Eine Methode hat einen Kopf und einen Rumpf in geschweiften Klammern. Tippe auf die Teile des Methodenkopfs:

{ … }

Tippe auf ein Teil.

Unsere Hunde sollen sagen können, ob man sie alleine daheim lassen kann. Dafür bekommt die Klassenkarte im unteren Fach eine Methode:

Hund
name: String
alter: Integer
istStubenrein: Boolean
kannAlleineBleiben(): void

Bausteine „Methode“, „if“, „println“

Die Methode bauen

Das Methodengerüst

  1. Die Methode gehört zum Bauplan. Wechsle deshalb oben in den Reiter Hund.
  2. Tippe auf den Baustein Methode. Es öffnet sich der Dialog „Baue Deine neue Methode“.
  3. Gib als Namen kannAlleineBleiben ein. Bei der Frage nach der Rückgabe bleibt void stehen, denn die Methode gibt nur etwas aus. Parameter brauchst du keine. Tippe auf Einfügen.
Hat alles geklappt?

Unter den Attributen sollte jetzt, mit einer Leerzeile Abstand, das leere Methodengerüst stehen.

Der Rumpf: eine Verzweigung

Die Methode soll prüfen, ob der Hund stubenrein ist. Wenn ja, sagt sie, dass er alleine bleiben kann, sonst nicht. So eine Verzweigung baust du mit if und else. Schau dir zuerst an, wie der fertige Rumpf aussehen soll:

Fertigen Code der Methode aufdecken

Diesen Code baust du jetzt mit Bausteinen nach:

  1. Der Cursor blinkt im Rumpf der leeren Methode. Tippe auf den Baustein if.
  2. Im Dialog trägst du als Bedingung istStubenrein == true ein und setzt den Haken bei else. Rechts siehst du schon die Vorschau des Codes. Tippe auf Einfügen.
  3. Der Cursor steht jetzt gleich im Rumpf der if-Anweisung (also innerhalb der geschweiften Klammern). Falls nicht, platziere ihn dort mit Finger, Maus oder Tastatur.
  4. Tippe auf den Baustein println und schreibe in die Klammern: name + " kann alleine bleiben."
  5. Platziere den Cursor genauso im Rumpf von else, also in der leeren Zeile zwischen } else { und }.
  6. Noch einmal println, diesmal mit name + " sollte nicht alleine bleiben."
Rot unterstrichen?

JPad prüft deinen Code schon beim Schreiben. Eine rote Wellenlinie zeigt einen Fehler. Was nicht stimmt, siehst du rechts in der Ansicht Probleme. Tippst du dort auf einen Fehler, springt JPad an die richtige Stelle.

Die Methode aufrufen

  1. Wechsle in den Reiter Hauptprogramm und gehe ans Ende.
  2. Schreibe in eine neue Zeile h1. und wähle aus den Vorschlägen kannAlleineBleiben(). Schließe mit ; ab.
  3. Darunter dasselbe für h2.
  4. Starte dein Programm mit ▶ oben rechts.

Die Ausgabe

Alles, was dein Programm mit println schreibt, erscheint in der Ansicht Ausgabe rechts. Jeder Hund antwortet mit seinem eigenen Namen, denn name ist jeweils das Attribut des Hundes, dessen Methode gerade läuft:

Ausgabe
Bello kann alleine bleiben.Cara sollte nicht alleine bleiben.
Und wo ist jetzt der Lernpfad?

Beim Start schaltet JPad die rechte Ansicht auf Ausgabe, damit du sofort siehst, was dein Programm schreibt. Der Lernpfad ist nicht weg, er liegt nur dahinter.

  • iPad quer: Tippe rechts oben auf den ersten Reiter mit dem Wegweiser-Symbol .
  • iPad hochkant: Tippe unten in der Leiste auf Lernpfad, und mit Code kommst du zurück zum Editor.
Experiment

Cara bekommt Hilfe vom Hundetrainer. Setze im Hauptprogramm h2.istStubenrein auf true und starte noch einmal. Was sagt Cara jetzt?

Lösung anzeigen
Cara kann alleine bleiben. Die Bedingung istStubenrein == true ist jetzt auch für Cara wahr, deshalb läuft der if-Teil. Stell den Wert danach wieder auf false.

Zuschauen

Schritt für Schritt im Diagramm

Mit ▶ läuft dein Programm in einem Rutsch durch. Mit dem Knopf Schritt kannst du ihm dagegen beim Arbeiten zusehen, Zeile für Zeile. Am besten siehst du das im Diagramm.

  1. Öffne rechts die Ansicht Diagramm und tippe oben auf Objekte.
  2. Tippe oben auf Schritt. Das Programm startet und hält sofort vor der ersten Zeile an. Diese Zeile ist gelb markiert: Sie ist als Nächstes dran.
  3. Tippe weiter auf Schritt und beobachte das Diagramm: Erst taucht eine Karte h1 : Hund auf, alle Attribute noch null (leer). Dann bekommt Bello nach und nach Name, Alter und istStubenrein. Danach entsteht Cara.
  4. Bei h1.kannAlleineBleiben(); springt JPad mit dem nächsten Schritt in den Reiter Hund, direkt in die Methode. Du siehst, welcher Teil der Verzweigung ausgeführt wird.

Klassenkarte oder Objektkarte?

Tippe im Diagramm oben abwechselnd auf Klassen und Objekte.

Klassenkarte (Klassen)

Zeigt den Bauplan: Hund mit den Attributen, ihren Datentypen und der Methode. Es gibt sie genau einmal.

Objektkarte (Objekte)

Zeigt einen gebauten Hund: oben unterstrichen h1 : Hund, darunter die aktuellen Werte, zum Beispiel name = "Bello". Es gibt so viele Objektkarten, wie Hunde gebaut wurden.

Abkürzung: der Haltepunkt

Bei langen Programmen dauert es, mit Schritt bis zur spannenden Stelle zu kommen. Tippe stattdessen auf die Zeilennummer einer Zeile: Links erscheint ein oranger Punkt, ein Haltepunkt. Startest du jetzt mit ▶, läuft das Programm normal los und hält erst vor dieser Zeile an. Noch einmal auf die Nummer tippen entfernt den Haltepunkt.

Die kleinen Schritt-Knöpfe

Solange das Programm angehalten ist, erscheinen neben Schritt zwei weitere Knöpfe: Methode überspringen führt einen Methodenaufruf in einem einzigen Schritt aus, Methode verlassen läuft bis zum Ende der aktuellen Methode. Mit ■ beendest du das Programm. Und weißt du nicht mehr, welcher Knopf was macht? Finger drauflegen!

Kopieren

Code übernehmen und abgeben

Bisher hast du alles selbst gebaut. Manchmal gibt dir ein Lernpfad aber auch fertigen Code mit. Dann steht über dem Code ein Knopf Kopieren, wie hier: ein dritter Hund, h3.

  1. Tippe oben am Code auf Kopieren. Der Knopf zeigt kurz „Kopiert“.
  2. Wechsle in JPad in den Reiter Hauptprogramm und setze den Cursor in eine neue, leere Zeile am Ende.
  3. Halte den Finger in diese Zeile und wähle Einsetzen. Auf einer Tastatur geht auch ⌘ + V.
  4. Starte das Programm. Was sagt Rex?
Lösung anzeigen
Rex kann alleine bleiben.

Deinen Code kopieren, zum Beispiel für eine Abgabe

Oft sollst du deinen Code auf einer Lernplattform abgeben, etwa in einer Aufgabe in mebis. Dafür hat JPad oben in der Kopfzeile, gleich nach dem Projektnamen, zwei Kopier-Knöpfe:

Code aller Dateien kopieren

Kopiert den Code aller Reiter auf einmal, hier also Hauptprogramm und Hund. Das brauchst du, wenn das ganze Projekt abgegeben werden soll.

Code dieser Datei kopieren

Kopiert nur den Code des gerade geöffneten Reiters, zum Beispiel nur die Klasse Hund.

Danach wechselst du zur Lernplattform, hältst den Finger in das Antwortfeld und wählst Einsetzen. Unsicher, welcher Knopf welcher ist? Finger drauflegen, JPad erklärt es dir.
